# MARUDER FOOTWEAR Website

A responsive static website made with HTML, CSS and JavaScript. It is ready to upload to GitHub and deploy on Vercel.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, collection filters and WhatsApp order actions

## Publish on GitHub
1. Create a new repository on GitHub (for example `maruder-footwear`).
2. Upload all four files/folders from this project. Keep `index.html`, `style.css` and `script.js` in the repository root.
3. Commit the upload.

## Deploy on Vercel
1. Sign in to Vercel and choose **Add New → Project**.
2. Import the GitHub repository.
3. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.
4. Click **Deploy**.
