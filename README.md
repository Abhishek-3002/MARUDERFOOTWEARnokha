# MARUDER Shoes Store
Responsive static storefront with white glass UI, product catalogue, brand filters, animated reveal effects, local shopping cart and WhatsApp enquiry checkout.

## Deploy on Vercel
- Framework preset: Other
- Root directory: ./
- Build command: empty
- Output directory: ./

## Cart and checkout
Cart is stored in the visitor's browser localStorage. Checkout opens WhatsApp (+91 6376004627) with selected items, UK sizes, quantities and indicative subtotal. This is an enquiry flow, not online payment or inventory reservation.

## Price and product note
Visible prices are indicative market-reference prices researched from Indian brand-store listings, not confirmed MARUDER selling prices. They must be approved by the store owner before being treated as sale prices. Product images are illustrative style references and may not show the exact product model. Confirm authenticity, model, price, stock and size before order acceptance.
